Open your apps folder

Each band app lives in its own folder, with a layout.json. Choose the folder that holds your apps. An empty folder is fine for a first app.

The editor opens this folder again next time.

  1. 1Design Add buttons. Each one sends one signal, from bb01 to bbff.
  2. 2Build zmake turns layout.json into a .bin file.
  3. 3Install Mi Band Bridge puts the app on the band.

Build tools are missing

Mi Band App Editor needs Python 3, Pillow and zmake to build an app. Nothing else works until you install them.

Run in terminal

Then restart the editor.

It checks the tools when it starts.
